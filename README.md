# 依洛嘉採購管理台

GitHub Pages 靜態前端。此 repository 僅含公開介面與虛構示範資料，不包含主檔、報價檔案、LINE 帳號識別碼或任何金鑰。

目前狀態：網站可使用示範模式。受保護的登入與回寫後端尚待部署授權，`BACKEND_ENABLED=false`；公司資料查詢及修改未啟用。以下為啟用後的流程。

## 使用

管理員私訊 LINE 採購助理「網頁登入」，取得一次性登入碼後登入網站。登入碼 10 分鐘有效；工作階段 8 小時有效，只保存於分頁 sessionStorage。伺服器每次請求重新檢查既有管理員權限。

搜尋品項 → 編輯 → 預覽差異 → 確認 → 修改紀錄查看 Excel 回寫結果。

第一版只修改測試主檔的 INCI、幣別、單價、計價單位、MOQ、製造商、保存期限與備註。不能改品名、供應商身分或分類，不能清空欄位或刪除資料。同步電腦必須在線；沿用既有備份、主檔版本比對與工作去重機制。

LINE 一般查詢可能讀取不同的查詢主檔；目前不會把測試資料寫入正式查詢主檔。查詢價格為主檔登記值，不是保證有效的報價。

## 發布

在 GitHub Pages 選擇從 main 分支的根目錄發布。頁面只使用原生 HTML、CSS、JavaScript，無建置步驟。後端為既有採購助理的 /web/ 受保護端點，由本機專案另外維護與部署。主檔不放入 GitHub。
